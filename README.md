# 50 Hands-On SOC Operations and SIEM Projects

A practical, authorized blue-team portfolio covering security operations, SIEM engineering, detection development, threat monitoring, incident investigation, and response.

## Structure

- Beginner: Projects 01–15
- Intermediate: Projects 16–35
- Advanced: Projects 36–50

Each project includes objectives, scope, prerequisites, lab setup, guided workflow, sample commands or queries, expected observations, triage, remediation, validation, reporting, and three clearly labeled simulated training illustrations. All activities use owned systems, isolated labs, synthetic telemetry, or explicitly authorized environments.
